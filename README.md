# Task Manager (CLI)

A simple command-line task manager built with **Java, JDBC, and PostgreSQL**.

## What it does

- Register users
- Login / Logout
- Create tasks
- List tasks
- Update task status
- Delete tasks

## Stack

- Java
- JDBC
- PostgreSQL
- Maven
- SLF4J + Logback

## Architecture

CLI → Service → DAO → PostgreSQL
